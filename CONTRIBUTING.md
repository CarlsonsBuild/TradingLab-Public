# Contributing to TradingLab

TradingLab is an independent, human-led quantitative research software project. The core implementation and operational control plane are private.

## Ways to help
- Review public conceptual design documents for clarity and correctness.
- Suggest reproducible testing methodologies and data quality checks.
- Discuss safe PAPER-only research workflows, validation, reproducibility and monitoring.
- Submit self-contained examples using synthetic or openly licensed data.
- Propose improvements to public documentation and accessibility.

## Boundaries
Do not request or submit broker credentials, secrets, private source code, private test fixtures, internal infrastructure paths, proprietary strategy parameters or account identifiers. No live trading, no production database writes, no deployment and no bypass of safety controls.

## Getting in touch
Reach out through the official Zavmino channel: https://www.youtube.com/@Zavmino .

## Proposed public issue categories
Documentation correction; reproducibility design; synthetic test harness; data quality methodology; accessibility/UI; security concern (report privately, not in a public issue).

## Reproducible contributions
Include a minimal synthetic fixture, expected output, failing test, fix and passing test output. State Python version and a source hash. Do not upload real account or runtime data. Run the public test command in README before proposing changes. There is no public source license grant for TradingLab-Core; this kit offers no access to proprietary implementation. A private security reporting channel must be agreed with the owner before sending vulnerability details.
